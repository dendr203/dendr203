# Hi, I'm Daniel 👋

**Firmware developer** at [ACRIOS Systems](https://www.acrios.com) and **Cybersecurity master's student** at VŠB – Technical University of Ostrava.
I build low-power IoT devices, from bootloaders and radio stacks to on-device scripting and cryptography. I am also interested in machine learning and AI development in games.

- 🔧 3+ years of professional experience in **embedded C** for battery-powered IoT devices
- 🔐 Master's thesis on **post-quantum cryptography for low-power devices**
- 🖨️ Self-taught **3D modeler**: I design parts in Fusion that fix real-world problems

## 💼 What I do at work

At ACRIOS I develop firmware and custom solutions for customers' smart metering and IoT devices:

- **Device firmware & bootloaders** in C for STM32 microcontrollers (L0, L4, WLE), including secure firmware update paths
- **Wireless connectivity:** LoRaWAN, NB-IoT and LwM2M (object model, observe/notify, power-aware sleep handling)
- **Applied cryptography:** AES payload encryption, key derivation from OTP memory, security logging
- **Lua scripting API:** designing and extending the API that customer Lua scripts use on the devices
- **Low-power engineering:** battery consumption accounting, persistent counters in SRAM/NFC EEPROM, data integrity (CRC)
- **Tooling:** Python scripts for testing, production and key handling; GitLab CI/CD pipelines
- Working directly with customers to turn their requirements into delivered firmware + script packages

ML portfolio from my BSc and MSc studies, focused on game data and game AI:
